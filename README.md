📱 Nitaq 
🌟 Overview
Nitaq is an advanced Android application designed to streamline attendance tracking, verification, and management with high security and efficiency. The project emphasizes secure biometric authentication, clean architecture, and localized user experiences supporting both Arabic and English languages.
🛠️ Tech Stack
• Programming Language: Java  
• IDE: Android Studio
• Version Control: Git & GitHub  
• Core APIs: BiometricPrompt, AppCompat, Localized Resources
✨ Key Features
• 🔒 Biometric Authentication: Secure check-in and check-out verification using device biometrics.
• 🌐 Localization Support: Full dynamic support for switching between Arabic and English interfaces.
• 📊 Interactive Dashboard: Real-time tracking of attendance days, absence counts, and timestamps.
